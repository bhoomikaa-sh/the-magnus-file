# the-magnus-file
An unofficial cinematic tribute website inspired by I'am Turning Into a Vampire

## About the Project

The Magnus Files is a fan-made website inspired by the story and characters of *I'm Turning Into a Vampire*. I wanted to create a place where the different parts of the story could be explored and organised instead of putting everything on one page.

The idea was to give the website the feeling of a mysterious archive, where every page reveals another part of the story. I chose a dark visual style to match the atmosphere of the series.

This project was also a way for me to practise building a multi-page website using HTML and CSS.

## What's Inside?

The website has five main pages:

- Home: The main entrance to The Magnus Files.
- Episode Archives: A collection of episode records from the series.
- Character Files: Information about Marion, Magnus, Jake and Leonard.
- Vampire Lore: A place for the supernatural details, mysteries and vampire-related information.
- Evidence Room: A collection of important clues and incidents from the story.

Each page has its own purpose, but they are connected through the navigation menu.

## How to View the Project Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Use the navigation menu to explore the other pages.

You can also use the Live Server extension in VS Code.

## How I Built It

I started by creating the homepage and setting up the basic structure of the website. After that, I worked on the other pages one by one.

I created separate HTML files for the episode archives, character files, vampire lore and evidence room. I used a shared CSS file to keep the overall design consistent across the website.

I also added character images and worked on the layout, spacing, typography and navigation so that the pages felt connected.

## Challenges and What I Learned

One of the things I had to work on was keeping multiple pages organised while making sure they all looked like part of the same website.

I also learned more about connecting HTML pages, organising image files, using CSS for layouts and making changes through GitHub commits.

Setting up GitHub Pages was another part of the process. I am currently working through a deployment issue with GitHub.

Building this project helped me understand how a website comes together beyond just writing individual HTML elements.
